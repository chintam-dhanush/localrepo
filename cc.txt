Step 3: Configure a domain using Route 53
This step requires a little clarification.
Route 53 does not automatically give you a free, usable domain such as example.com. You need to register a domain or use one you already own.
If you have a domain, follow these steps:
1.	Open Route 53 in the AWS Console.
2.	Select Hosted zones.
3.	Create a hosted zone for your registered domain if you don't already have one.
4.	Open the hosted zone and select Create record.
5.	Enter www as the record name if you want to use www.yourdomain.com.
6.	Choose record type A.
7.	Enable Alias.
8.	Select Alias to CloudFront distribution.
9.	Select your CloudFront distribution.
10.	Create the record.
Before the custom domain works, you must also configure that domain as an alternate domain name on the CloudFront distribution and associate a suitable TLS certificate. For CloudFront, the certificate must be provisioned in the US East (N. Virginia) Region. Your domain's DNS must also point to the appropriate Route 53 nameservers. AWS Documentation

Step 1: Create the VPC

What does 10.0.0.0/16 mean?
It defines the IP address range available inside your VPC. We'll create a smaller subnet inside this range in the next step.


Step 2: Create a subnet inside MyVPC
A subnet is a smaller network inside your VPC. We'll create one for our EC2 instance.
1.	Open the VPC Dashboard in the AWS Console.
2.	In the left-side menu, find Subnets.
3.	Click Create subnet.
4.	Under VPC ID, select the VPC you created: MyVPC.
5.	Enter these details:
Setting	Value
Subnet name	MySubnet
Availability Zone	Choose any one available
IPv4 subnet CIDR block	10.0.1.0/24
6.	Click Create subnet.
Step 3: Enable public IP assignment
Since we'll eventually launch an EC2 instance that can connect to the internet, let's enable automatic public IPv4 assignment for this subnet.
1.	Go to Subnets and select MySubnet.
2.	Click Actions → Edit subnet settings.
3.	Enable Auto-assign public IPv4 address.
4.	Click Save.
Note: This setting allows instances launched in this subnet to receive a public IPv4 address automatically. The Internet Gateway and route table still need to be configured before the instance can communicate with the internet.


Step 4: Create an Internet Gateway
An Internet Gateway (IGW) connects your VPC to the internet. We'll create one and attach it to MyVPC.
A. Create the Internet Gateway
1.	Open the VPC Dashboard in the AWS Console.
2.	In the left menu, find Internet gateways.
3.	Click Create internet gateway.
4.	Enter the following name:
MyInternetGateway
5.	Click Create internet gateway.
B. Attach it to your VPC
Creating the gateway alone isn't enough—we must attach it to MyVPC.
1.	Select the newly created MyInternetGateway.
2.	Click Actions → Attach to a VPC.
3.	Select MyVPC.
4.	Click Attach internet gateway.
✅ You should now see the gateway's state as Attached, with MyVPC listed as its attached VPC.
Why do we need it? The Internet Gateway provides a path between your VPC and the internet, provided the route table and security settings are configured correctly.



Step 5: Create a Route Table
A route table contains rules that determine where network traffic from your subnet should go.
We'll create a route table and configure it to send internet traffic through your Internet Gateway.
A. Create the route table
1.	Open the VPC Dashboard in AWS.
2.	In the left menu, click Route tables.
3.	Click Create route table.
4.	Enter these details:

Name	MyRouteTable
VPC	MyVPC
5.	Click Create route table.

1.	Select MyRouteTable.
2.	Open the Subnet associations tab.
3.	Click Edit subnet associations.
4.	Select MySubnet.
5.	Click Save associations.
Now your subnet is associated with your route table.
C. Add the internet route
1.	With MyRouteTable selected, open the Routes tab.
2.	Click Edit routes → Add route.

0.0.0.0/0	Select Internet Gateway, then choose MyInternetGateway

What does 0.0.0.0/0 mean?
It represents all IPv4 destinations. This route tells AWS to send traffic destined for outside the VPC through the Internet Gateway.
Your VPC now has a route for internet traffic. The subnet can function as a public subnet when the necessary routing and public IP settings are in place.


Step 6: Create a Security Group
A Security Group acts as a virtual firewall for your EC2 instance. It controls which incoming and outgoing traffic is allowed.
Your lab record says to allow only the required traffic, such as SSH (22) and HTTP (80).

Important security note:
•	SSH (22): Select My IP to restrict remote access to your current public IP address.

Aim: To create and execute a simple Hello World application using AWS Lambda.
What is AWS Lambda?
AWS Lambda lets you run code without creating or managing a server. You write a function, AWS executes it when triggered, and you receive the result.
We'll follow your lab notebook's procedure.
Step 1: Open AWS Lambda
1.	Open the AWS Management Console.
2.	Search for Lambda.
3.	Open the Lambda service.
4.	Check that you're in the AWS Region you want to use.
Step 2: Create a Lambda function
1.	Click Create a function.
2.	Select Author from scratch.
3.	Enter these details:
Setting	Value
Function name	HelloWorld
Runtime	Python 3.14, or the latest Python runtime available
Architecture	x86_64
Permissions	Create a new role with basic Lambda permissions
4.	Click Create function.
AWS will create your function and an execution role. The basic role allows Lambda to write execution logs to CloudWatch.
Cost note: A simple Lambda function that you invoke a few times is generally within the Lambda free tier, if eligible. CloudWatch logging and other AWS services may have separate charges, so we'll keep this experiment minimal.
Step 3: Enter the Python code
After your function is created:
1.	Scroll to the Code tab.
2.	Find the code editor.
3.	Replace the existing code with this:
def lambda_handler(event, context):
return {
'statusCode': 200,
'body': 'Hello World!'
}
4.	Click Deploy to save your changes.
What does this code do?
•	lambda_handler(event, context) is the function Lambda executes.
•	event contains input data sent to the function.
•	context provides information about the execution environment.
•	statusCode: 200 indicates success.
•	body contains the message we want to return.
Step 4: Create a test event
1.	Click Test.
2.	If prompted to configure a test event, select Create new event.
3.	Enter an event name, such as HelloWorldTest.
4.	Keep the default JSON test event if one is provided.
5.	Click Save or Create, depending on the interface.
Step 5: Execute the function
1.	Select your test event.
2.	Click Test.
3.	Wait for the execution result.
You should see a response similar to:
{
  "statusCode": 200,
  "body": "Hello World!"
}
Your execution should also show a successful result.
Expected output:
Hello World!
Result: The Hello World application was successfully created and executed using AWS Lambda.

package hadoop;

import java.io.IOException;
import java.util.Iterator;
import java.util.StringTokenizer;

import org.apache.hadoop.fs.Path;
import org.apache.hadoop.io.IntWritable;
import org.apache.hadoop.io.LongWritable;
import org.apache.hadoop.io.Text;
import org.apache.hadoop.mapred.FileInputFormat;
import org.apache.hadoop.mapred.FileOutputFormat;
import org.apache.hadoop.mapred.JobClient;
import org.apache.hadoop.mapred.JobConf;
import org.apache.hadoop.mapred.MapReduceBase;
import org.apache.hadoop.mapred.Mapper;
import org.apache.hadoop.mapred.OutputCollector;
import org.apache.hadoop.mapred.Reducer;
import org.apache.hadoop.mapred.Reporter;
import org.apache.hadoop.mapred.TextInputFormat;
import org.apache.hadoop.mapred.TextOutputFormat;

public class ProcessUnits {

    public static class E_EMapper extends MapReduceBase
            implements Mapper<LongWritable, Text, Text, IntWritable> {

        public void map(LongWritable key, Text value,
                OutputCollector<Text, IntWritable> output,
                Reporter reporter) throws IOException {

            String line = value.toString();

            StringTokenizer s = new StringTokenizer(line);

            String year = s.nextToken();
            String lasttoken = null;

            while (s.hasMoreTokens()) {
                lasttoken = s.nextToken();
            }

            int units = Integer.parseInt(lasttoken);

            output.collect(new Text(year), new IntWritable(units));
        }
    }

    public static class E_EReduce extends MapReduceBase
            implements Reducer<Text, IntWritable, Text, IntWritable> {

        public void reduce(Text key, Iterator<IntWritable> values,
                OutputCollector<Text, IntWritable> output,
                Reporter reporter) throws IOException {

            int maxavg = 30;

            while (values.hasNext()) {

                int val = values.next().get();

                if (val > maxavg) {
                    output.collect(key, new IntWritable(val));
                }
            }
        }
    }

    public static void main(String args[]) throws Exception {

        JobConf conf = new JobConf(ProcessUnits.class);

        conf.setJobName("max_electricityunits");

        conf.setOutputKeyClass(Text.class);
        conf.setOutputValueClass(IntWritable.class);

        conf.setMapperClass(E_EMapper.class);
        conf.setCombinerClass(E_EReduce.class);
        conf.setReducerClass(E_EReduce.class);

        conf.setInputFormat(TextInputFormat.class);
        conf.setOutputFormat(TextOutputFormat.class);

        FileInputFormat.setInputPaths(conf, new Path(args[0]));
        FileOutputFormat.setOutputPath(conf, new Path(args[1]));

        JobClient.runJob(conf);
    }
}

package org.myorg.demo;

import java.io.IOException;
import java.util.StringTokenizer;

import org.apache.hadoop.io.IntWritable;
import org.apache.hadoop.io.LongWritable;
import org.apache.hadoop.io.Text;
import org.apache.hadoop.mapreduce.Mapper;

public class MaxTemperatureMapper
        extends Mapper<LongWritable, Text, Text, IntWritable> {

    @Override
    public void map(LongWritable key, Text value, Context context)
            throws IOException, InterruptedException {

        StringTokenizer tokenizer =
                new StringTokenizer(value.toString());

        String year = tokenizer.nextToken();
        int temperature = Integer.parseInt(tokenizer.nextToken());

        context.write(new Text(year), new IntWritable(temperature));
    }
}



nano src/org/myorg/demo/MaxTemperatureReducer.java

package org.myorg.demo;

import java.io.IOException;

import org.apache.hadoop.io.IntWritable;
import org.apache.hadoop.io.Text;
import org.apache.hadoop.mapreduce.Reducer;

public class MaxTemperatureReducer
        extends Reducer<Text, IntWritable, Text, IntWritable> {

    @Override
    public void reduce(Text key, Iterable<IntWritable> values,
                       Context context)
            throws IOException, InterruptedException {

        int maxTemp = Integer.MIN_VALUE;

        for (IntWritable value : values) {
            if (value.get() > maxTemp) {
                maxTemp = value.get();
            }
        }

        context.write(key, new IntWritable(maxTemp));
    }
}

package org.myorg.demo;

import org.apache.hadoop.conf.Configuration;
import org.apache.hadoop.fs.Path;
import org.apache.hadoop.io.IntWritable;
import org.apache.hadoop.io.Text;
import org.apache.hadoop.mapreduce.Job;
import org.apache.hadoop.mapreduce.lib.input.FileInputFormat;
import org.apache.hadoop.mapreduce.lib.output.FileOutputFormat;

public class MaxTemperature {

    public static void main(String[] args) throws Exception {

        if (args.length != 2) {
            System.err.println(
                "Usage: MaxTemperature <input> <output>");
            System.exit(2);
        }

        Configuration conf = new Configuration();
        Job job = Job.getInstance(conf, "Maximum Temperature");

        job.setJarByClass(MaxTemperature.class);
        job.setMapperClass(MaxTemperatureMapper.class);
        job.setCombinerClass(MaxTemperatureReducer.class);
        job.setReducerClass(MaxTemperatureReducer.class);

        job.setOutputKeyClass(Text.class);
        job.setOutputValueClass(IntWritable.class);

        FileInputFormat.addInputPath(job, new Path(args[0]));
        FileOutputFormat.setOutputPath(job, new Path(args[1]));

        System.exit(job.waitForCompletion(true) ? 0 : 1);
    }
}
